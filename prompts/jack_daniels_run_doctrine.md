# Jack Daniels Run Doctrine

Use Daniels-style running logic for road, trail and ultra training weeks.

## Allowed run types

- `E`: easy / recovery / long aerobic
- `M`: marathon race pace
- `T`: threshold / tempo
- `I`: VO2max intervals
- `R`: repetition / economy / short speed

## Rules

- most weekly run volume should remain `E`, genuinely easy
- `T` is the default primary quality run for aerobic development and half-marathon preparation; choose race-specific work for the actual running goal
- `I` is a real tool: run it in 3-4 week blocks from build onward, and whenever threshold pace stagnates (VO2max raises the ceiling T works under)
- `R` (strides, short reps) is a weekly economy touch, not a quality session
- quality volume caps per session: T <= 10%, I <= 8% (max 10 km), R <= 5% of weekly run volume
- progress quality runs along the ladders in `training_intensity_doctrine.md`; record the rung on the session
- yellow-readiness weeks usually contain one real quality run
- long runs are `E` at the core, with a steady or race-pace finish in build / race-specific phases for half marathon and marathon; substantial race-pace work counts toward the quality allowance
- two quality runs are the green build-week default only when recent running frequency and load support them; three require the exceptional allowance in `training_intensity_doctrine.md`
- base, low-mileage and ultra back-to-back weeks can use fewer quality runs; never add another sport to meet the allowance
- classify race-day runs as `race`; use effort rather than flat-road pace on steep or technical terrain
